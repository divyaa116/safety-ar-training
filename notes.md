# Project Notes: AR Safety Training (Mini Project)

## Goal
Mobile AR safety training + certification for industrial workers. Tamil voiceover (plus English). Review 2 demo on Android phone.

## Tech choices
- Web app (PWA) with Google model-viewer for AR (ARCore / Scene Viewer), hosted on GitHub Pages
- Plain HTML/CSS/JS only, no frameworks
- APK will be made at the end using PWABuilder
- Voiceover: text-to-speech tool (mp3 files named ta1.mp3, ta2.mp3 ... in repo root)

## Module being built
Module 1: Fire and Explosion Response (PASS method)
